Orkas is an open-source, local-first desktop AI workforce. A Commander turns goals into executable plans and coordinates specialist agents in parallel or sequence through one chat.

For developer work, Orkas can coordinate built-in agents and supported external local agents such as Claude Code, Codex and OpenCode. Packaged installers are available for macOS and Windows; Linux runs from source. The core application is free; model usage and optional services may cost extra.
