YYLO orchestrates coding agents from the terminal: `yy` and `yylo` (equivalent launchers) run agent loops, repeatable workflows, and receipt-backed repository changes. `yy init` bootstraps a Git workspace with typed task, validation, merge, and release-readiness boundaries, and `yy ledger` / `yy benchmark` delegate to the independent YYLO Ledger and YYLO Benchmark packages.
